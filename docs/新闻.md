新闻错误判断原因
1.新闻获取不及时，市场已消化
2.新闻权重不高，不能影响市场
3.同类新闻持续发布 影响力度衰减
4.市场逻辑和叙事改变
（低可能性）5.缺失其他重要新闻1、引入优质新闻源：金十、律动
 
1.1 金十（外汇、黄金宏观新闻）
 
- 接入方式：WebSocket实时流（优先）、Webhook回调、REST轮询（不推荐，延迟高）

- 内容：非农、CPI、美联储讲话、地缘、大宗商品；自带事件日历、预期值、前值、实际值。
 
注意：公开网页不能做程序抓取，需要商业API接口；网页爬虫会被反爬，延迟高，不适合毫秒级。
 
1.2 律动（加密新闻）
 
- 接入：API/WebSocket，覆盖加密政策、项目公告、链上重大事件。
 
补充信源：Benzinga、Finlight，海外原生财经快讯，专门服务量化事件驱动，亚秒级推送。

2、毫秒级对接非农、鲍威尔美联储新闻（核心难点）
 
普通网页轮询做不到毫秒级，轮询最少几百ms‑1s，行情已经走完。
